A preview of DashyNMS v2.0.0 for **Windows, macOS and Linux**.

These notes cover changes since [preview 11](https://github.com/DashyNMS/desktop/releases/tag/v2.0.0-preview.11).

## New

- **Spotlight on log cards.** Each Event log and Graylog card on the Dashboard can be kept to some devices, a device group or a location, using the same picker as Intelligence. You can put a "Core routers" card next to a "Leeds" card. A card without a Spotlight still shows the whole network, so existing dashboards don't change.
- **Sign DashyNMS Mobile in with a QR code.** Settings, Server has a **Sign in DashyNMS Mobile** card. Choose **Show** and scan the code with your phone's camera to sign the app in to the same server. The code stays hidden until you ask for it and disappears again after a minute. The phone uses this computer's API token, so the card suggests creating a separate token for it.
- **Export logs to CSV.** Graylog, device Graylog, device Event log and device Alert history can be copied or saved as CSV. Exports follow the current sort order and search, and cover the current Graylog page or the device log entries already loaded.

## Trying this preview

Report issues through [GitHub issues](https://github.com/DashyNMS/desktop/issues), including your operating system and, on Linux, your desktop environment.

Mac downloads use Developer ID signing and Apple notarisation. Windows distribution signing remains tracked in [#109](https://github.com/DashyNMS/desktop/issues/109).
