A preview of DashyNMS v2.0.0 for **Windows, macOS and Linux**. This is the first preview of the Avalonia app on all three platforms, replacing the former Windows WPF app.

These notes cover changes since [preview 4](https://github.com/DashyNMS/desktop/releases/tag/v2.0.0-preview.4), which introduced Intelligence, grouped alerts and LibreNMS 26.10 support.

## New

- **One desktop app on Windows, macOS and Linux.** The dashboard, devices, alerts, logs, maps, rules, settings and Intelligence now use the same Avalonia app. The old WPF app has been retired.
- **Native downloads.** Windows x64 Setup, macOS Intel and Apple Silicon disk images, and Linux x64 and ARM64 AppImages. Each includes the matching Intelligence network tools, a SHA-256 checksum and a source revision record.
- **Notifications and startup on every platform.** Notifications use the operating system's notification service, and Settings can start DashyNMS when you sign in.
- **Event log and Alert log auto-refresh.** Choose an interval, just as with Graylog. Refresh pauses when the view is inactive and keeps your filters and selection.

## Improved

- **Windows upgrades keep your profile.** Installing over 1.x reuses your settings, saved sign-in, encrypted data and install location. Installer checks cover upgrades from both 1.0 and 1.1.
- **Updates choose the right download.** The app selects the package for your operating system and processor and checks its SHA-256 checksum. Windows updates use Setup; macOS explains how to replace the app from the disk image; Linux AppImage updates can replace the current file and roll back if replacement fails. Package-manager installations use their existing update route.
- **Slow sensor requests.** Sensors have longer to load, and a failed refresh keeps the last good readings. Missing or invalid readings show as unavailable, with clearer loading and last-refresh information.
- **What's New after an update.** The app shows the changes when you first open a new version.

## Fixed

- **Close to the background.** Closing the main window keeps DashyNMS running when close-to-tray is enabled. Exit still quits the app.
- **Device Details windows.** Only the main window appears in the taskbar. Opening a device restores the main window, and closing one device leaves the others open. Caption buttons reach the right edge when Device Details opens maximised.
- **Windows branding.** Notifications and the executable use DashyNMS, with the app's logo on notifications and the tray fallback.
- **Alert colours.** The sidebar badge uses the worst severity among the alerts it counts.
- **Demo alerts.** Demo mode shows all ten example alerts, including the two acknowledged ones.
- **Intelligence activity icons.** Success and stopped markers sit centrally in their circles.
- **Sensor details and graphs.** Unknown units are preserved, graph legends stay with their readings, and warning limits are handled consistently.

## Trying this preview

Please report Windows upgrade problems and first-run issues on macOS or Linux, including which desktop you use on Linux (for example GNOME or KDE), through [GitHub issues](https://github.com/DashyNMS/desktop/issues).

Windows distribution signing is still tracked in [#109](https://github.com/DashyNMS/desktop/issues/109). macOS packages are ad-hoc signed and are not yet notarised; distribution signing and notarisation are tracked in [#255](https://github.com/DashyNMS/desktop/issues/255).

**Privacy:** Intelligence sends your questions, and the network information needed to answer them, to OpenAI. Web search can also send search terms to external search providers. Review **Settings, Intelligence** before using it.
