A preview of DashyNMS v2.0.0 for **Windows, macOS and Linux**.

These notes cover changes since [preview 12](https://github.com/DashyNMS/desktop/releases/tag/v2.0.0-preview.12).

## New

- **Export Intelligence chats.** The export button at the top of Intelligence saves the open chat as a PDF or a Markdown file. It works for saved chats and for the temporary chat. The PDF has real, selectable text on A4 pages, with tables, code, graphs and clickable sources. A Markdown export puts its graphs in a folder beside the file. An answer that was still being written, or was stopped, is marked as incomplete. Lookup records and sign-in details are left out, and the file is saved only where you choose.
- **Device logos in Device Details.** A device's details now show its own logo from your LibreNMS server instead of the generic device symbol. DashyNMS keeps the last 20 logos on your computer. To keep the symbol and fetch nothing, turn off **Show device logos** in Settings, Theme.
- **A user guide for every system.** New [guides](https://github.com/DashyNMS/desktop/blob/master/docs/guide/README.md) explain how to install, update and remove DashyNMS on Windows, macOS and Linux. They also cover where it keeps your data and what works differently on each system.

## Fixed

- **Event log export button.** The export button in a device's Event log stays in view at the end of the search row, at any window size. Screen readers announce the export buttons as "Export".
- **Quitting.** DashyNMS runs its shutdown once, however you quit, so a second Quit request can't run it again.

## Privacy

The [privacy policy](https://dashynms.pckp.net/desktop/privacy/) now describes 2.0 on all three systems. It covers the optional error reports and usage measurements, what Intelligence sends to OpenAI, sensor definition downloads, and where your data is kept on each system. Nothing about what DashyNMS collects has changed.

## Trying this preview

Report issues through [GitHub issues](https://github.com/DashyNMS/desktop/issues), including your operating system and, on Linux, your desktop environment.

Mac downloads use Developer ID signing and Apple notarisation. Windows distribution signing remains tracked in [#109](https://github.com/DashyNMS/desktop/issues/109).
