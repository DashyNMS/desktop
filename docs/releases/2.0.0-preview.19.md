A preview of DashyNMS v2.0.0 for **Windows, macOS and Linux**.

These notes cover changes since [preview 18](https://github.com/DashyNMS/desktop/releases/tag/v2.0.0-preview.18).

## New

- **Intelligence is easier on your servers.** It now makes at most 8 requests at a time to each of LibreNMS, Unimus and Graylog, however many lookups a question needs. The rest wait their turn, and a request no longer times out while it waits. When lookups have queued, the provider answering is told, so it can ask for less at once.

## Fixed

- **Crashes at startup on Apple silicon Macs.** DashyNMS could crash a moment after opening, or stall while an update was installing and be rolled back. The macOS download is larger as a result.
- **Opening DashyNMS when it's already running.** The second copy crashed. It now hands over to the running one and quits.
- **A source that's limiting requests.** When LibreNMS, Unimus or Graylog answers that it's being asked too often, Intelligence says so instead of reporting an unexplained error.

## Trying this preview

Report issues through [GitHub issues](https://github.com/DashyNMS/desktop/issues), including your operating system and, on Linux, your desktop environment. For a provider problem, include the provider, its version from **Settings › Providers**, and what it said, but not device names or addresses.

The two startup fixes haven't been tried by hand on a Mac yet. If DashyNMS still crashes or stalls as it opens, please report it with your Mac's model and macOS version.

Mac downloads use Developer ID signing and Apple notarisation. Windows distribution signing remains tracked in [#109](https://github.com/DashyNMS/desktop/issues/109).
