A preview of DashyNMS v2.0.0 for **Windows, macOS and Linux**.

These notes cover changes since [preview 9](https://github.com/DashyNMS/desktop/releases/tag/v2.0.0-preview.9).

## Changed

- **Settings are easier to navigate.** App information, server information, updates and diagnostics have separate sections. About shows the desktop and bundled network tools versions. Messages distinguish settings you need to apply from actions that have already completed.
- **Optional performance measurements.** Usage sharing can now include startup and screen loading times, API and Intelligence response timings, UI stalls, memory use, update outcomes and counts of selected app features. Existing launch-only consent does not enable these measurements. The updated prompt asks before expanding what you share.
- **Optional session health.** When you explicitly allow both error reports and the current usage/performance choice, DashyNMS can report whether sampled app sessions ended normally, failed or were interrupted. Existing consent does not enable this automatically.
- **More useful managed error locations.** Error reports can include application source file names and line numbers where available. Absolute local paths, source code and exception messages remain excluded.

Sharing remains optional. You can change your choices in Settings, Diagnostics. See the [privacy notes](https://github.com/DashyNMS/desktop/blob/master/PRIVACY.md) for the measurements, exclusions and local storage limits.

## Fixed

- **Reopening the macOS window.** Clicking the Dock icon brings back the main or sign-in window when DashyNMS is already running.
- **Closing a fullscreen macOS window to the tray.** DashyNMS leaves native fullscreen before hiding the window, so it can be reopened normally.

## Trying this preview

Report issues through [GitHub issues](https://github.com/DashyNMS/desktop/issues), including your operating system and, on Linux, your desktop environment.

Mac downloads use Developer ID signing and Apple notarisation. Windows distribution signing remains tracked in [#109](https://github.com/DashyNMS/desktop/issues/109).
