A preview of DashyNMS v2.0.0 for **Windows, macOS and Linux**.

These notes cover changes since [preview 17](https://github.com/DashyNMS/desktop/releases/tag/v2.0.0-preview.17).

## New

- **Choose who answers in Intelligence.** As well as ChatGPT, Intelligence can now answer with AI agents on your computer, each with your own sign-in and plan:
  - **ChatGPT through Codex**, as an alternative to signing in to ChatGPT in DashyNMS.
  - **Claude Code**, with a Claude plan or an Anthropic API key.
  - **GitHub Copilot**, through the Copilot CLI, on any Copilot plan, Free included.
  - **Gemini**, through Antigravity CLI, Google's terminal agent, with a free Google account or AI Pro or Ultra.

  DashyNMS starts each agent in a locked-down session. It can use only DashyNMS's read-only network tools, never its own shell, file or browser tools, and it never sees your projects, MCP servers or agent settings. Your LibreNMS, Graylog and Unimus credentials stay in DashyNMS.
- **Model picker.** Pick the provider, model and reasoning level for each chat from the picker beside the question box. It lists only providers that are ready. Under the question box, Intelligence shows how much of your plan's limit you've used, where the provider reports it.
- **Settings › Providers.** A new page lists your providers. Each one shows its connection, account, usage and executable, under two headings:
  - **Default setup**: the model and reasoning level new chats start with.
  - **Available models**: which models the picker shows.

  **Add provider** shows every supported provider, and opens the install page for any you don't have yet. The bin beside a provider removes it and keeps its chats.
- **Moving a chat to another provider.** Pick a model from another provider and DashyNMS asks first, then carries the chat's earlier questions and answers across so the new provider can continue. An **Agent changed** line marks where it happened.
- **Dashy's personality.** In **Settings › Intelligence › Personality**, describe how you'd like Dashy to sound, for example "Be blunt and brief." It changes tone and wording only: Dashy still checks its facts and says what it couldn't confirm. While it's on, **Custom personality** shows under the question box.

## Fixed

- **Device and alert names in answers.** An answer that mentioned a device or alert Intelligence hadn't looked up itself sometimes showed "Device 442" or "Alert 501". It now shows the device's name and state, or the alert's rule and severity, from DashyNMS's own lists.

## Before you ask

The first time you ask after updating, Intelligence shows its "what's sent" notice again. It now names every provider's company: OpenAI, Anthropic, GitHub and Google. The [Intelligence guide](https://github.com/DashyNMS/desktop/blob/master/docs/guide/how-to/intelligence.md) covers setting up each provider.

## Trying this preview

Report issues through [GitHub issues](https://github.com/DashyNMS/desktop/issues), including your operating system and, on Linux, your desktop environment. For a provider problem, include the provider, its version from **Settings › Providers**, and what it said, but not device names or addresses.

The agent providers were tested on Windows. On macOS and Linux they're built in the same way but haven't been tried by hand yet; reports are especially welcome.

Mac downloads use Developer ID signing and Apple notarisation. Windows distribution signing remains tracked in [#109](https://github.com/DashyNMS/desktop/issues/109).
