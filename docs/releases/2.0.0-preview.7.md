A preview of DashyNMS v2.0.0 for **Windows, macOS and Linux**.

These notes cover the sensor-definition updates since [preview 6](https://github.com/DashyNMS/desktop/releases/tag/v2.0.0-preview.6).

## New

- **Names and colours for sensor states.** Supported numeric state readings now show meaningful labels and, where the definition supplies an authoritative status, severity colours. Labels appear in Health, Device Details and dashboard sensors. Raw readings remain available in tooltips and graphs.
- **Sensor definitions in Settings.** Enable definitions, use the official catalogue or a compatible public GitHub repository, check the catalogue version and last update, and choose **Update definitions** to refresh manually. Apply source or enable changes before updating.
- **Independent catalogue updates.** Enabled installations check for updated definitions automatically, downloading definitions for device operating systems as needed. Routine catalogue changes do not require a new app release. The official catalogue is currently **26.10.2+catalogue.2**, with mappings imported from LibreNMS's discovery sources.
- **The same definitions in Intelligence.** The bundled network tools read the installation's sensor definitions so Intelligence can use the same state labels and statuses as the app.

## Improved

- **More precise state matching.** Definitions can take device context and sensor OIDs into account, including mappings inherited through LibreNMS operating-system groups and shared discovery code. Unsupported or conflicting mappings remain unresolved rather than selecting a guessed state.
- **Clearer unknown states.** A state value without a supported mapping is shown as **Unknown state**, with an explanation in its tooltip. Missing readings remain **No data**. State sensors no longer show numeric threshold progress bars.
- **Cached definitions after an offline restart.** Previously downloaded definitions remain available when the app restarts without a connection to the catalogue source.

## Using sensor definitions

Open **Settings, Sensor definitions**, enable **Use sensor definitions**, and apply the change. Definitions belong to this installation and survive sign-out. Turning the feature off and applying removes downloaded definitions and returns readings to their raw display.

Definitions add labels to readings; they do not change the sensor data or alert rules in LibreNMS. Coverage varies by device and sensor. Choose a custom repository only if you trust its publisher.

## Trying this preview

Please report issues through [GitHub issues](https://github.com/DashyNMS/desktop/issues), including your operating system and, on Linux, your desktop environment.

Windows distribution signing is tracked in [#109](https://github.com/DashyNMS/desktop/issues/109). macOS packages are ad-hoc signed and are not yet notarised; distribution signing and notarisation are tracked in [#255](https://github.com/DashyNMS/desktop/issues/255).

**Privacy:** Intelligence sends your questions, and the network information needed to answer them, to OpenAI. Web search can also send search terms to external search providers. Review **Settings, Intelligence** before using it.
