A preview of DashyNMS v2.0.0 for **Windows, macOS and Linux**.

These notes cover changes since [preview 7](https://github.com/DashyNMS/desktop/releases/tag/v2.0.0-preview.7).

## New

- **Signed macOS distribution builds.** Intel and Apple Silicon downloads now pass Developer ID signing and Apple notarisation before publication. The app, bundled network tools and native helpers are signed, and notarisation tickets are attached to the app and disk image.
- **Rotating Intelligence starter questions.** Blank chats offer four questions from a rotating catalogue. Suggestions take cached devices and open alerts into account. Existing messages and unfinished drafts are kept.
- **Optional single chat mode.** Under **Settings, Intelligence**, choose one temporary conversation without saving its messages, draft, tool history or context on this device. Existing saved chats are kept. Turning the mode off discards the temporary chat and restores the saved chats. Sign-in is retained.
- **Choose how updates download.** Under **Settings, About**, turn off **Download updates automatically** for notifications only. You can still start an update manually. Automatic downloads remain enabled by default, and installation still needs your action. Linux package-manager installations remain notification-only.

## Fixed

- **Recovered alert cycles.** Earlier recovered incidents no longer inflate current fault counts or create misleading expanders. Active groups exclude recovered siblings, including migrated whole-device rows. Distinct live faults remain visible.
- **LibreNMS browser sign-in on every desktop.** Windows, macOS and Linux can use the browser sign-in and API-token creation flow. Manual token entry remains available. The browser uses the operating system's certificate trust.
- **Readable unmonitored connections.** Unknown connections in Device Details retain readable text while navigation remains unavailable.
- **macOS full-screen spacing.** The window header no longer reserves traffic-light space while full screen.
- **Clearer update controls.** Available updates have a more visible action. The preview option and update-check button align in About.

## Check the Mac download

Install the app in Applications, then run this in Terminal:

```bash
spctl --assess --type execute --verbose=4 /Applications/DashyNMS.app
```

The expected result is `accepted` with `source=Notarized Developer ID`.
To verify the app's signature separately, run:

```bash
codesign --verify --deep --strict /Applications/DashyNMS.app
```

The signature check exits successfully without output. macOS performs its own
Gatekeeper checks when opening a downloaded app; there is no additional
verification page inside DashyNMS.

## Trying this preview

Report issues through [GitHub issues](https://github.com/DashyNMS/desktop/issues), including your operating system and, on Linux, your desktop environment.

Windows distribution signing remains tracked in [#109](https://github.com/DashyNMS/desktop/issues/109).

Intelligence sends your questions and the network information needed to answer them to OpenAI. Web search can send search terms to external search providers. Single chat mode controls local conversation storage. Review **Settings, Intelligence** before using it.
