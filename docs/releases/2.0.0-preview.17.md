A preview of DashyNMS v2.0.0 for **Windows, macOS and Linux**.

These notes cover changes since [preview 16](https://github.com/DashyNMS/desktop/releases/tag/v2.0.0-preview.16).

## Fixed

- **Device states in Intelligence.** The network tools no longer call a device down when LibreNMS didn't say whether it was up, or up or down when it's ignored. They report it as unknown or ignored instead. The network overview and the per-location counts list those devices separately, so their numbers add up. You can also ask for ignored devices, or devices with no reported state.
- **Request measurements on LibreNMS 26.10.** If you share usage and performance measurements, alert checks against LibreNMS 26.10 and later now count as alert requests, not "other", so they compare with older servers.

## Trying this preview

Report issues through [GitHub issues](https://github.com/DashyNMS/desktop/issues), including your operating system and, on Linux, your desktop environment.

Mac downloads use Developer ID signing and Apple notarisation. Windows distribution signing remains tracked in [#109](https://github.com/DashyNMS/desktop/issues/109).
