A preview of DashyNMS v2.0.0 for **Windows, macOS and Linux**.

These notes cover changes since [preview 16](https://github.com/DashyNMS/desktop/releases/tag/v2.0.0-preview.16).

## Fixed

- **Device states in Intelligence.** When LibreNMS doesn't report whether a device is up, Intelligence now calls it unknown rather than down. A device set to be ignored is shown as ignored rather than up or down. The network overview, its status card and the per-location counts list these devices separately, so the numbers add up. Intelligence can also list ignored devices, or devices with no reported state.
- **Request measurements on LibreNMS 26.10.** If you share usage and performance measurements, alert checks against LibreNMS 26.10 and later now count as alert requests, not "other", so they compare with older servers. On servers before 26.10, the one check per connection that looks for the newer alert list also counts as an alert request.

## Trying this preview

Report issues through [GitHub issues](https://github.com/DashyNMS/desktop/issues), including your operating system and, on Linux, your desktop environment.

Mac downloads use Developer ID signing and Apple notarisation. Windows distribution signing remains tracked in [#109](https://github.com/DashyNMS/desktop/issues/109).
