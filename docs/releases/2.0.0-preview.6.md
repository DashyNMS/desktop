A preview of DashyNMS v2.0.0 for **Windows, macOS and Linux**.

These notes cover changes since [preview 5](https://github.com/DashyNMS/desktop/releases/tag/v2.0.0-preview.5), including the updates merged on 23 October 2026.

## New

- **Ask Intelligence about an object.** Right-click a device, port, sensor, alert, device group or location and choose **Ask Intelligence** to start a new chat with that object in Spotlight. This also works across dashboard widgets, including pinned devices, graphs, top interfaces and log entries.
- **Add objects from answers to Spotlight.** Objects mentioned in an Intelligence reply can be added to the current chat's Spotlight for follow-up questions.
- **Apply Settings without closing.** Use **Apply** to save changes and keep Settings open.

## Improved

- **Device overview layout.** Overview cards fit the available space more effectively.
- **Clearer navigation and icons.** Device graphs, resources and sensors have clearer icons, and Health uses the same sensor icon as Device Details.
- **Cleaner downloads.** GitHub releases show only the five app downloads. Checksums and build records remain available in the Actions artifacts.

## Fixed

- **Intelligence context menus.** Object menus open on the first right-click.
- **Starting Intelligence chats.** New chats receive keyboard focus, with **Ctrl+N** available to start a chat.
- **Intelligence choices while busy.** Model and answer-detail choices stay readable while an answer is being generated.
- **Unmonitored neighbours.** Neighbours that are not monitored in LibreNMS remain readable in Device Details.
- **Settings notification guidance.** Removed the outdated preview warning about notifications.
- **macOS application menu.** The application menu shows **DashyNMS**.

## Trying this preview

Please report issues through [GitHub issues](https://github.com/DashyNMS/desktop/issues), including your operating system and, on Linux, your desktop environment.

Windows distribution signing is tracked in [#109](https://github.com/DashyNMS/desktop/issues/109). macOS packages are ad-hoc signed and are not yet notarised; distribution signing and notarisation are tracked in [#255](https://github.com/DashyNMS/desktop/issues/255).

**Privacy:** Intelligence sends your questions, and the network information needed to answer them, to OpenAI. Web search can also send search terms to external search providers. Review **Settings, Intelligence** before using it.
