A preview of DashyNMS v2.0.0 for **Windows, macOS and Linux**.

These notes cover changes since [preview 19](https://github.com/DashyNMS/desktop/releases/tag/v2.0.0-preview.19).

## New

- **Sensor questions on large networks.** Intelligence can answer "is anything running hot?" when your LibreNMS account isn't allowed the network-wide sensor list, however many devices there are. It reads devices one by one for about 20 seconds, alerting ones first, and says how many it covered. Ask again within a few minutes to carry on. The answer also names the LibreNMS permission that would cover them all at once.

## Fixed

- **Events on busy networks.** "Did anything reboot this week?" only reached back a few hours on a network with a busy event log. Intelligence now reads much further back, especially when the question asks for one kind of event, a device, a group or a location. When part of the time still couldn't be read, the answer says which part and why.

## Trying this preview

Report issues through [GitHub issues](https://github.com/DashyNMS/desktop/issues), including your operating system and, on Linux, your desktop environment. For a provider problem, include the provider, its version from **Settings › Providers**, and what it said, but not device names or addresses.

Mac downloads use Developer ID signing and Apple notarisation. Windows distribution signing remains tracked in [#109](https://github.com/DashyNMS/desktop/issues/109).
