# DashyNMS user guide

DashyNMS is a desktop app for LibreNMS. It tells you when an alert fires, and lets you look into your devices, alerts, logs and maps without opening a browser.

These guides cover DashyNMS 2.0, which runs on Windows, macOS and Linux. Until 2.0 is released, you can try it from the [preview releases](https://github.com/DashyNMS/desktop/releases).

- [Getting started](getting-started.md), with what you need and how to sign in the first time.
- [Install on Windows](install-windows.md)
- [Install on macOS](install-macos.md)
- [Install on Linux](install-linux.md)
- [Where DashyNMS keeps your data](your-data.md), which lists the folders on each system and explains how to start again from scratch.
- [Differences between Windows, macOS and Linux](platform-differences.md)

Something not working, or not covered here? [Open an issue](https://github.com/DashyNMS/desktop/issues) and tell us which system you're using.
